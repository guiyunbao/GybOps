# 任务、文章与内容资产

返回 [新手使用手册](README.md)。

这三项目都在侧栏 **内容** 组。推荐顺序是：先在内容资产里准备标题和知识，再创建任务，最后到内容管理里检查文章。

## 任务管理

任务把模型、提示词、标题库、知识库、图片、作者、分类、生成数量和发布方式存成一套可以重复执行的配置。要批量生产时用任务。只改一篇已经写好的文章时，直接去内容管理。

侧栏点击 **任务管理**。页内导航有三项：

- **任务管理**：任务列表
- **Worker 状态**：后台执行进程是否在线
- **最近 Job**：每一次执行的结果和失败原因

列表上先看任务状态、文章统计和最近一次原因。空列表时，页面会提示还没有任务。

第一次建议这样做：

1. 确认 [AI模型配置](system.md#ai模型配置) 里至少有一个检测通过的对话模型。
2. 在内容资产里准备一个只有几条标题的标题库。
3. 点击 **创建任务**。名称写清楚用途，生成数量填 `1`。
4. 选上一步的模型和标题库。发布方式保持人工审核。先不要选择外部渠道。
5. 保存后启动一次。然后打开 **最近 Job**，等到状态离开排队。

启动后，任务列表的文章统计里会出现草稿。Job 记录里能看到这次执行对应的任务。成功生成后，可以从记录进入文章。

标题不够、模型不可用或 Worker 不在线时，任务会停住。先看 Job 里的失败原因，再看 [任务一直不动](troubleshooting.md#任务一直不动)。正在运行的任务如果被修改，已经进入队列的那一次仍使用保存时的配置。

队列、调度和失败重试的维护说明留在部署文档。日常只需要确认 **Worker 状态** 里的进程是「工作中」或「空闲」，而不是「已失联」。

## 内容管理

内容管理保存任务生成或手工写下的文章，也从这里进入专题、分类、审核和回收站。

侧栏点击 **内容管理**。页内导航是：

- **文章列表**
- **专题列表**
- **分类管理**
- **审核中心**
- **垃圾箱**

右上角还有 **创建文章** 和 **人工发布**。

### 文章

文章保存标题、正文、摘要、作者、分类、图片、SEO 信息和质检结果。常见状态有草稿、待审核、已发布。删除后先进入垃圾箱。

在文章列表先看状态和质检标记。打开一篇文章后，先读正文，再看风险扫描和 AI 质检结论。

第一次建议这样做：

1. 等任务生成那 1 篇草稿，或点击 **创建文章** 自己写一篇短文。
2. 补上分类。还没有分类时，先到 **分类管理** 新建一个，名称和地址标识都用稳定、可读的文字。
3. 保存后重新打开，确认正文还在。
4. 等 AI 质检结束。结论是待复核或阻断时，先改正文再检查，确认可用后再发布。
5. 发布后打开前台对应页面。

发布成功后，文章状态变为已发布，前台能打开。计划在未来时间发布的文章，到点之前仍不会出现在前台。

质检策略、人工放行和评分细则见 [AI 质检运行手册](../ai-quality-inspection-runbook.md)。文章发不出去时看 [文章发不出去](troubleshooting.md#文章发不出去)。列表支持准备 Markdown 批量导出；导出文件有数量和下载次数限制，过期后要重新准备。

### 专题

专题是围绕一个主题组织起来的页面，可以挂文章、单独审核和按计划公开。它和单篇文章分开管理。

在内容管理页内导航点击 **专题列表**。先选择站点，再看状态筛选。状态包括草稿、待审核、已审核并等待计划发布、已公开、已撤回和回收站。

第一次使用普通文章任务时，可以先不建专题。需要一个主题页时，从专题列表新建一个，写好标题并保存为草稿，预览确认后再公开。

草稿保存在列表里。公开之后，前台对应地址可以打开。缺来源时，专题会停在「缺来源」，先补文章或资料再生成。

从专题类任务产生的结果，也可以在任务列表点进「查看本任务专题」。

### 分类

分类决定文章在后台和前台如何归组，地址标识会进到前台路径里。

在内容管理页内导航点击 **分类管理**。列表里先看名称和已有文章数。

第一次建议新建一个分类，例如「产品说明」，地址标识用简短英文或拼音，创建后不要再频繁改动。

新分类出现在列表中，创建文章和任务时可以选到它。已经有文章使用的分类，删除会受到限制。先把文章改到其他分类，再删除。

### 人工发布

人工发布用来登记「这篇文要由人发到第三方平台」的工单。系统记录平台、账号、执行人、计划时间和回执。最后在第三方平台上的提交，仍由操作的人确认。

在内容管理页点击右上角 **人工发布**，进入人工发布工作台。也可以在某一篇文章上创建工单。

第一次使用时，先确认文章已经审核通过。创建一条工单，填好平台和执行人，先不要连接浏览器。做完后在工单详情里能看到状态。

工单保存在工作台列表中。执行人完成后，把发布地址和结果填回去。

要用 Chrome 在支持的平台上填充草稿，先在右上角 **账户与权限** 里批准浏览器客户端。扩展的安装、配对和撤销见 [Chrome 运营助手](../browser-operations-runbook.md)。扩展不保存第三方平台的密码。

## 内容资产

内容资产集中存放任务会反复用到的关键词、标题、图片、作者和知识。改动会影响之后新建的任务。正在跑的那一次，通常仍使用开始时记下的内容。

侧栏点击 **内容资产**。页内导航是：

- **AI知识库**
- **关键词库**
- **标题库**
- **图片库**
- **作者管理**
- **URL智能采集**（仅具备受保护工作流权限的账号看得到）

页面上半部分是知识资产。这里有 **新建知识库**、**知识原子化** 和 **管理知识库**。下半部分是关键词、标题、图片和作者的入口。

### 标题库

标题库存放待生成的标题。任务每生成一篇，会消耗可用标题。标题不够时，任务会停住或按循环规则复用，具体以保存任务时的设置为准。

打开 **标题库**，新建一个库，进入详情后添加标题。

第一次建议手工加 2 到 3 条明确的标题，供第一次闭环使用。确认可用后，再使用 **AI 生成标题**。生成前要有检测通过的对话模型，以及一个已经有内容的关键词库。

标题出现在库详情里，创建任务时可以选到这个库。AI 生成在队列里跑，提交后到生成记录里看进度。抽查重复和跑题的标题，再拿去跑正式任务。

### 关键词库

关键词库给标题生成和任务提供主题词。

打开 **关键词库**，新建一个库，逐条添加或导入。

第一次建议写入 5 到 10 个你们真实要写的主题词。导入后抽查有没有空行和重复。

关键词出现在库详情中。标题生成和任务可以引用这个库。词太短或大量重复时，生成结果会漂。先改词，再重新生成一小批标题。

### AI知识库

知识库存放给文章生成和质量检查使用的资料，支持 Markdown、文本和 Word。系统会把资料切成小段，供后续检索。

在内容资产页点击 **新建知识库**，或从导航进入 **AI知识库**。填写名称，贴入一段已经核对过的资料，保存。

第一次建议只放一小节产品说明或 FAQ。保存后打开知识库详情，确认能看到切片。切片还在生成时，稍等再刷新。

详情里能看到资料和切片。任务选择这个知识库后，新文章会参考这些内容。资料改过之后，依赖它的旧质检结果会过期，需要重新检查。

向量进度停住时，到 AI模型配置看有没有可用的 Embedding 模型。没有 Embedding 模型时，系统仍可以用关键词方式检索，强制刷新真实向量则需要模型可用。

页面上的 **知识原子化** 进入企业知识项目。适合把多份来源整理成可审查的草稿，确认后再发布到普通知识库。第一次闭环不必使用它。创建项目、添加来源、看解析结果、确认草稿，再发布。发布前的草稿留在项目里，任务读取的是已经发布到知识库的内容。

### 图片库

图片库给文章配图。上传时会检查文件类型和大小。

打开 **图片库**，新建一个库，上传 1 张你有权使用的图片。

创建需要配图的任务之前，先确认库里已经有图。第一次只写文字时，可以先不建图片库。

图片出现在库详情中，任务和文章编辑器可以选到它。文章仍然没有图时，检查任务是否选择了这个库，以及文件是否上传成功。

### 作者管理

作者是文章上的署名，包含名称、简介和头像。

打开 **作者管理**，新建一位作者，写上对外展示的名字。

第一次建议只建一位，并在任务或文章里固定选用。这样前台署名一致。

作者出现在列表中，编辑文章时可以选到。已有文章使用的作者，删除前要先改文章署名。

### URL智能采集

URL智能采集从外部网页抓取正文，先预览，确认后再写入知识或素材。只有具备受保护工作流权限的账号能在内容资产导航里看到 **URL智能采集**。

打开该页，粘贴一篇结构清楚的文章地址，提交后等待预览。先看标题和正文是否完整，再确认入库。

第一次使用时，选一篇公开、正文清晰的文章页。首页、列表页和需要登录的页面很难抽出干净正文。

预览里能看到提取结果。确认后，目标知识库或素材里出现这条内容。失败时看该次任务的状态，区分打不开、内容过大和解析不完整。采集不会绕过站点自己的访问限制。
