# GEOFlow 新手使用手册

这份手册给第一次打开后台的人。它按侧栏里的真实菜单说明每个功能做什么、从哪里进去、第一次先做哪一步，以及做完后页面上应该出现什么。

同一份说明也放在后台里，登录前就能打开。地址是后台前缀加上 `/getting-started`，默认是 `/geo_admin/getting-started`。登录页和登录后的用户菜单都有入口。

安装、升级和生产部署见 [部署文档](../deployment/DEPLOYMENT.md)。模型共享、AI 质检、Chrome 运营助手和命令行的细节留在各自的运行手册里，文中会给出链接。

## 本地地址

用仓库里的本机启动脚本把服务跑起来之后，默认地址是：

- 前台：<http://localhost:18080>
- 后台：<http://localhost:18080/geo_admin/login>
- 账号：`admin`
- 密码：`password`

端口由 `APP_PORT` 控制，后台前缀由 `ADMIN_BASE_PATH` 控制。如果你改过这两项，把上面的端口和 `geo_admin` 换成自己的值。生产环境请立刻修改默认密码，步骤见 [部署文档](../deployment/DEPLOYMENT.md)。

## 后台地图

登录后，左侧菜单分成这些组：

| 位置 | 菜单 | 用来做什么 |
|------|------|------------|
| 顶部 | AI 工作台 | 用对话问「这个功能在哪、下一步怎么做」 |
| 数据 | 数据中心 | 看内容、访问、线索、AI 可见性和分发结果 |
| 内容 | 任务管理 | 按标题和知识批量生成文章 |
| 内容 | 内容管理 | 看文章、专题、分类、审核和回收站 |
| 内容 | 内容资产 | 准备关键词、标题、图片、作者和知识库 |
| 分发 | 分发管理或内链投放 | 把文章发到其他站点，或管理站内链接 |
| 系统 | AI配置器 | 配置模型、提示词和搜索信源 |
| 系统 | 网站设置 | 改品牌、首页、表单、用户、安全和更新 |

具备受保护工作流权限的管理员（通常是超级管理员）在「分发」组看到 **分发管理**。普通管理员在同一位置看到 **内链投放**。分发管理页面里仍然可以进入内链投放。看不到某个菜单时，先看 [侧栏少了一项](troubleshooting.md#侧栏少了一项)。

侧栏下方的「最近」会记下你打开过的页面。右上角用户菜单进入 **账户与权限**，可以改自己的资料，并管理已配对的浏览器客户端。

## 建议阅读顺序

1. 先按下面的「第一次闭环」做出一篇草稿。
2. 做的过程中打开 [系统](system.md) 里的 AI配置器，以及 [内容](content.md) 里的任务和内容资产。
3. 文章发布、前台能打开之后，再读 [数据中心](data.md)。
4. 需要发到其他网站时，再读 [分发与内链](distribution.md)。
5. 某一步卡住时，直接看 [常见卡点](troubleshooting.md)。

## 第一次闭环

目标是生成 1 篇草稿，先不向外分发，并在文章页确认结果。队列和定时任务要处于运行中；用本机 Docker 启动时，这两个服务会一起起来。

1. 打开后台并登录。
2. 进入 **系统 → AI配置器 → AI模型配置**，新增一个对话模型，保存后做连接检测。检测通过后再继续。
3. 进入 **内容 → 内容资产**，打开 **标题库**，新建一个库，手工加入 2 到 3 条标题。
4. 仍在内容资产页，点击 **新建知识库**，写入一小段你确认过的资料，保存后确认知识库出现在列表中。
5. 进入 **内容 → 任务管理**，点击 **创建任务**。生成数量填 `1`，选择刚才的模型和标题库，发布方式保持需要人工审核。先不要绑定外部渠道。
6. 保存后启动这一次运行。页面提示已提交，只说明请求进入了队列。到 **Worker 状态** 和 **最近 Job** 看它是否开始执行。
7. 进入 **内容 → 内容管理** 的 **文章列表**。出现草稿后打开它，看正文、风险扫描和 AI 质检。质检还在排队时先等它结束。
8. 确认内容可用后，再在文章页发布。然后打开前台首页，确认这篇文章能被看到。

做完这一圈，再增加生成数量、图片、自动发布和分发渠道。
