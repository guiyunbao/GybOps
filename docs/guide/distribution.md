# 分发与内链

返回 [新手使用手册](README.md)。

文章先在本站发布成功，再考虑发到其他站点。本站前台能打开，不依赖这里的渠道。

侧栏 **分发** 组的菜单因账号而不同：

- 具备受保护工作流权限的管理员看到 **分发管理**。内链投放在分发管理页面的页内导航里。
- 普通管理员看到 **内链投放**，看不到分发管理、托管站点和渠道配置。

## 分发管理

分发管理把已发布的文章和部分站点设置送到外部渠道。渠道类型包括 GEOFlow Agent、WordPress 和通用 HTTP API。密钥加密保存，页面上只显示必要摘要。

侧栏点击 **分发管理**。页内导航包括：

- **托管渠道站点**
- **查看队列**
- **同步全部外部站点**
- **内链投放**

渠道列表先看每条渠道是启用还是暂停，以及最近一次健康检查。

第一次建议这样做：

1. 确认本站至少有 1 篇已发布文章。
2. 先只浏览渠道列表，确认自己知道目标站点的地址和接口权限。
3. 新建一个渠道，填名称、类型、目标地址和认证信息，保存。
4. 做健康检查。检查通过后，用那 1 篇文章做一次分发。
5. 打开 **查看队列**，等到状态变成成功，再去目标站点核对页面。

健康检查通过后，渠道列表显示可用。队列里会出现这一次发布，并带有远端结果。目标站点上能打开对应文章。

检查通过只说明当时的连接和认证可用。正式发布仍可能因为正文、图片或远端规则失败。失败时在队列里读错误，修好渠道后再用页面上的重试。远端已经出现文章时，先核对远端编号，避免再发一份。

暂停渠道后，新的分发不会再送出去。已经发出的请求要在队列里看最终结果。

删除渠道前，系统会先做影响预检。预检结果和当时看到的不一致时，先停止，重新看一遍影响范围再确认。

### 托管渠道站点

托管渠道站点由 GEOFlow 分配子域名、文章和发布配额，并生成站点地图等发现文件。适合还没有自己的目标站、又希望用子域名发出一组内容的情况。

在分发管理页内导航点击 **托管渠道站点**。先看站点状态和配额。

第一次使用前，确认域名解析、证书和代理已经按部署文档准备好。只想在 `localhost` 看本站时，跳过托管站点。

准备完成后，站点状态变为可用，分配到的文章可以在对应域名打开。站点打不开时，依次看域名解析、证书、站点档案和文章是否已经分配。释放站点前同样要完成影响预检。

### 同步站点设置

**同步全部外部站点** 用来把品牌、导航等受支持的设置发到 GEOFlow Agent 渠道，并让目标站重建页面。执行前会进入预览。

打开预览，核对将要变更的站点和差异。确认范围后再继续。

第一次只接了一个渠道时，先在预览里看这一站的差异。批量同步时，每一站有自己的结果，失败的站可以单独再试。

预览页能列出目标和变更。同步后到该渠道的队列或站点上核对页面。目标站不支持的项目会被跳过。

## 内链投放

内链投放管理文章之间的链接目标和投放活动，用来在已发布内容里加入指向站内页面的链接。

超级管理员从 **分发管理** 的页内导航进入 **内链投放**。普通管理员从侧栏 **内链投放** 进入。页内可以查看总览、目标、导入、投放活动和设置。

第一次建议这样做：

1. 先发布至少两篇相关文章。
2. 打开内链投放总览，看现有目标是否为空。
3. 添加一个指向已发布文章的目标，保存。
4. 用预览看链接会出现在哪里，确认后再启用投放。

总览里能看到这个目标。预览里能看到计划插入的链接。文章页上出现链接后，点一次确认地址正确。

还没有已发布文章时，先回到内容管理发布。投放结果和文章正文冲突时，先停用该活动，再改目标。
